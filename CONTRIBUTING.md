# Contributing

- `npm test` runs the tests (Node 18+).
- `npm run build` renders the example icons to `dist/`.
- `npm run docs:dev` runs the documentation site with real renders.
- Keep the studio generic: no domain icons in `engine/` or `examples/`.
- New badge: add it to `engine/badges.js` (glyph inside the 36,36 r10 circle) and to `docs/guide/variants-badges.md`.
- New animation: add it to `PRESETS` in `engine/build.mjs`.
